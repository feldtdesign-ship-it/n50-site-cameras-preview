# N50 site with live cameras (preview)

Review copy of the North 50 Building Systems site with the V Wall and L Wall live cameras added. Not the live site. Set to stay out of search engines.

Cameras: Cloudflare Stream, live-only WebRTC, click to view, muted start. Viewing hours daily 7:00 AM to 5:00 PM Alaska time (one setting, `SCHED`, in index.html). Outside those hours the page shows the offline message. Add `?camtest=1` to the address to ignore the schedule while testing.

Only public playback IDs are in this page. No publishing addresses, keys or tokens.
